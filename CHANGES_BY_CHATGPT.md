# Изменения ChatGPT

Дата: 2026-07-02

## Что изменено

1. В модальное окно заявки добавлена кнопка `← На главную`.
   - Кнопка закрывает модальное окно.
   - После закрытия плавно возвращает пользователя к Hero-блоку (`#top`).
   - Дизайн не менялся радикально: добавлена компактная кнопка в стиле текущего интерфейса.

2. Исправлена логика выбранного автомобиля в заявке.
   - Раньше при выборе другой машины в выпадающем списке верхняя карточка в модальном окне могла оставаться старой.
   - Теперь изображение, название, бейдж, цена и месячный платеж в верхней карточке обновляются сразу после выбора машины в списке.
   - Дополнительно синхронизируется основной выбранный автомобиль на странице.

3. Hero-блок подключен через уже созданный компонент `MobileHero`.
   - Убрано дублирование Hero-разметки внутри `MobileLanding.tsx`.
   - Оптимизированное LCP-изображение сохранено без изменений.

## Проверка

- Выполнена TypeScript-проверка: `npx tsc --noEmit` — ошибок нет.
- `npm run build` в sandbox-среде не завершился из-за окружения: Next.js попытался скачать Linux SWC-пакет, но npm registry в этой среде защищен. Это не ошибка кода.

## Как проверить локально

1. Установить зависимости:

```bash
npm install
```

2. Проверить сборку:

```bash
npm run build
```

3. Запустить локально:

```bash
npm run dev
```

4. Проверить вручную:
   - открыть сайт на мобильной ширине;
   - нажать `Получить предложение`;
   - выбрать другую машину в списке;
   - убедиться, что верхняя карточка в форме меняется на выбранную машину;
   - нажать `← На главную` и убедиться, что окно закрывается и страница возвращается к Hero.


## Дополнительная правка

- Усилена логика кнопки «← На главную» в мобильной форме: теперь сначала выполняется прокрутка к Hero, затем закрывается модальное окно, и прокрутка повторяется через короткую задержку для стабильной работы на мобильных браузерах.
- Сохранена логика, при которой выбор автомобиля в форме обновляет верхнюю карточку выбранного автомобиля.
